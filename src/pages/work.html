WHAT THE WORK SHOWS

One product.
Several disciplines.

EDUFY is still in development, but it already demonstrates how Maxel connects product thinking, interface design and application development instead of treating them as separate hand-offs.

01 / PRODUCT

Structure the right experience.

User roles, feature priorities and flows are shaped before interface decisions are locked in.

02 / INTERFACE

Turn the structure into something clear.

Responsive screens and interaction patterns are designed around the actions students, teachers and administrators need to take.

03 / APPLICATION

Connect the visible product to the system behind it.

Account flows, administration tools and application logic are developed as part of the same product.
