How project inquiries on this website are handled.

Project inquiries

The contact form collects your name, email address, optional company, selected service, budget range, preferred timing, project message and permission to respond. These details are saved in the studio’s PostgreSQL database so Maximilian can review your request and contact you.

Access and follow-up

The inbox is restricted to the studio administrator. Submitting an inquiry does not subscribe you to marketing messages or send an automatic confirmation email. Contact Maximilian through his personal website if you want to discuss, correct or request removal of submitted information.

Security and service operation

The administrator login uses an essential session cookie. A keyed hash of the connection’s IP address is stored with inquiries to limit repeated submissions; the raw address is not stored in the inquiry record. The hosting provider may maintain standard access logs.

What to include

Please share only what is needed to discuss your project. Do not include passwords, payment details or sensitive personal records. This website includes no advertising trackers or analytics tools.
